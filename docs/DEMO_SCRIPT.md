# Demo video — 60 seconds, real prototype on screen (not slides)

Record the app, not a deck. One continuous take per scene if possible; cut between scenes, never fake a step.

## Shot list

| Time | Screen | Action / narration |
|---|---|---|
| 0:00–0:10 | Sender view | "$200 to Enugu. Rent $100, school $60, food $40." Split sliders move; quote panel shows $2.00 fee vs $12.72 World Bank average. Click Send. |
| 0:10–0:20 | Sender view → tracking | Escrow funded; three envelopes appear as Locked. Pickup code shown (blur all but last 2 digits on the recording if the code is live). "Five seconds, fractions of a cent." |
| 0:20–0:35 | Agent view | Agent enters the 6-digit code, confirms float, clicks Confirm pickup. Food envelope flips Locked → Released; cash amount in NGN shown. |
| 0:35–0:50 | Tracking view | School envelope releases direct to the school wallet. All three envelopes show receipts; click one receipt → Stellar Explorer (testnet) transaction page loads. |
| 0:50–0:60 | Tracking view | Summary: "$200 sent, $198 delivered to its purposes, $2 fee. Every envelope receipted." End card: repo + live demo URLs. |

## Recording notes

- Use mock mode for the rehearsal take; use testnet mode for the final take if the contract is deployed — and say which mode is on screen (it's in the header).
- If a testnet step is slow on the day, cut to the receipt, don't narrate over a spinner.
- Keep the cursor slow. Judges watch the money move, not the mouse.
- Audio: one voice, no music bed under narration.
